## 📑 Executive Summary

**DHEER.EXE** documents the unexplainable cellular and corporate divergence of an ordinary professional who woke up one morning as a 6-foot, 200-pound giant panda. 

Armed with acetate-frame reading spectacles, a rotation of high-fashion corporate polos, non-retractable black claws, and an industrial-grade bronze monsoon rain poncho, Dheer navigates sprint standups, hostile boardroom takeovers, and high-speed two-wheeler extractions.

This website is a state-of-the-art interactive prank experience crafted with **award-winning editorial art direction, pure Vanilla CSS, Web Audio API sound synthesis, an embedded interactive terminal, and a forensic photo inspection engine.**

## ⚡ Interactive Engine Features

### 1. 🎛️ Web Audio API Sound Synthesizer
- Built using zero external audio files — 100% synthesized in real time via the browser's native `AudioContext`.
- Features ambient low-frequency sci-fi drones (65.4 Hz warm C2 base), responsive UI click blips, forensic scanner tones, and crunchy bamboo consumption sound effects.
- Includes an animated equalizer visualization in the navigation bar.

### 2. 🔍 Forensic Lightbox Modal
- Click any photo across the site to enter **Deep Forensic Inspection Mode**.
- Animated laser scanner line animation across high-resolution imagery.
- Side panel detailing case reference numbers, attire analysis, environmental conditions, and camera EXIF metrics.
- Full keyboard navigation (`Esc` to exit, `←` / `→` arrows to cycle through artifacts).

### 3. 💻 Interactive Diagnostic CLI Terminal (`tty1`)
- Embedded bash-like terminal emulator inside the Telemetry section.
- Type real commands to inspect system logs and unlock hilarious easter eggs:

| Command | Action |
|:---|:---|
| `help` | Display manual and available command flags |
| `status` | Print real-time biological, behavioral, and telemetry readouts |
| `whoami` | Print official species dossier & clearance level |
| `photos` / `ls` | List all 7 forensic photographic artifacts with reference IDs |
| `inspect <1-7>` | Trigger the high-res forensic lightbox for that specific case study |
| `bamboo` | Dispatch emergency bamboo rations (+5 stalks) with confetti burst |
| `poncho` | Read engineering specs of the industrial bronze rain poncho |
| `standup` | Engage cubicle looming simulation protocol |
| `dheer` | Render ASCII art portrait of Dheer wearing glasses |
| `clear` | Wipe terminal screen buffer |

### 4. 🥽 Tactical Night-Vision HUD
- Instant one-click toggle in the header switches the entire interface into a phosphor-green military HUD with digital scanline overlays and radioactive glow aesthetics.

### 5. 🎋 Live Bamboo Feeders & Confetti Cannons
- Interactive `Deploy Bamboo Ration` and `Send Dheer Bamboo` buttons trigger celebratory multi-color confetti storms powered by `canvas-confetti`.

### 6. 🎯 Custom Inertia Magnetic Cursor
- Dual-ring physics cursor that dynamically morphs into an `INSPECT` targeting reticle when hovering over evidence cards.

## 🚀 Local Development

Clone the repository and run the local development server:

```bash
# Clone the repository
git clone https://github.com/PranavThakur07/ProjectDheer.git

# Navigate into the project folder
cd ProjectDheer

# Install dependencies
npm install

# Start the Vite development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

## 📦 Building for Production

To create an optimized, minified production bundle:

```bash
npm run build
```

The compiled static assets will be output to the `dist/` folder.

## ☁️ Zero-Config Netlify Deployment

This repository includes a pre-configured `netlify.toml` file:

```toml
[build]
  command = "npm run build"
  publish = "dist"

[[redirects]]
  from = "/*"
  to = "/index.html"
  status = 200
```

1. Log into your [Netlify](https://app.netlify.com/) account.
2. Click **Add new site** → **Import an existing project**.
3. Select **`PranavThakur07/ProjectDheer`**.
4. Netlify will automatically detect the build settings. Click **Deploy Site**!
